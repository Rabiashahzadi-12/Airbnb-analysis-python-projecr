# Airbnb Data Analysis with Python

## Project Overview:
This project explores Airbnb listing data using Python to practise data cleaning, data preprocessing, exploratory data analysis (EDA), and data visualization.
The analysis aims to understand patterns in Airbnb listings and explore factors such as pricing, room types distributions, and other listing across different neighborhoods, prices and room types distribution and reviews available in the dataset.

This project was completed as part of my learning journey by following a tutorial from a YouTube channel called *Theiscale* where I learned many things. Also I used **Matplotlib** for the visualizations instead of **Seaborn**( the one used in the video), while practicing rest of the techniques.

## Objectives

* Load and inspect the Airbnb dataset.
* Clean and preprocess the data for analysis.
* Explore important variables and patterns in Airbnb listings.
* Analyze listing prices and other relevant features.
* Create visualizations to communicate observations from the data.

## Project Workflow

* Loaded and inspected the dataset.
* Examined data types, missing values, irrelevant information and data quality.
* Cleaned and preprocessed the data.
* Conducted exploratory data analysis.
* Created visualizations using Matplotlib.
* Reviewed the results to understand patterns in the dataset.
